# TeamHub 球隊雲端整合管理平台 🏐

> 大學「雲端服務應用導論」期末實作專題  
> 專為大學運動球隊（排球隊）量身打造的一站式雲端管理平台。

---

## 🌟 第一階段：前端架構與 Dashboard 儀表板展示

第一階段專注於**使用者介面設計（UI/UX）**與**響應式前端體驗（RWD）**，不需安裝複雜環境或啟動資料庫，即可在任何瀏覽器中直接測試完整操作流程！

### 🎨 介面視覺規範
- **核心色系**：深邃海軍藍 (`#0f172a`)、純白底色 (`#ffffff`)、活力亮綠重點色 (`#10b981`)。
- **版型設計**：Dashboard 儀表板架構，左側導覽欄 + 頂部控制列 + 右側卡片式內容區。
- **響應式支援 (RWD)**：
  - 電腦端：固定左側邊欄，寬螢幕兩欄式儀表板。
  - 手機/平板端：自動縮合為頂部漢堡選單（☰），點擊滑出側邊欄與深色遮罩。

## 🚀 如何在電腦上開啟與測試（超簡單！）

### 方式 1：直接雙擊檔案開啟 (零門檻)
1. 在 Windows 檔案總管中開啟專案資料夾 `d:\cloud-115\teamhub`。
2. 找到 `index.html`，滑鼠對其**連按兩下 (雙擊)**。
3. 系統將自動以 Google Chrome 或 Microsoft Edge 開啟網站！

### 方式 2：使用瀏覽器開發人員工具測試「手機版」畫面
1. 在 Chrome 或 Edge 瀏覽器中開啟 `index.html`。
2. 按下鍵盤 `F12` 鍵（或點右鍵選擇「檢查」）。
3. 點擊開發者工具左上角的 **「切換裝置工具列 (手機/平板圖示)」**（快捷鍵 `Ctrl + Shift + M`）。
4. 選擇 iPhone 14 或 Pixel 7：
   - 觀察側邊欄是否自動收合。
   - 點擊左上角的 **「☰」漢堡按鈕**，測試側邊選單是否順暢滑出。
   - 點擊遮罩或任何選單項目，測試是否自動關閉選單並切換頁面。

## 🧪 功能測試清單與操作步驟

### 一、 球衣訂購管理模組測試 (已 100% 通過)
1. **隊員線上訂購與自動金額計算**：
   - 進入「球衣訂購管理」頁籤。
   - 選擇訂購隊員（如：王大明）、選擇球衣種類（如：練習服酒紅 NT$ 350）、尺寸（M）、數量（2）。
   - 觀察下方金額試算區塊是否即時更新為「單價 NT$ 350 × 2 件 = 總計 NT$ 700」。
   - 點擊「確認送出訂單」，清冊最上方立即出現新訂單，預設標記「未付款」。
2. **截止前編輯修改訂單**：
   - 在全隊訂單清冊任一筆訂單右側點擊「✏️ 修改」。
   - 頁面平滑滾動至上方表單，按鈕切換為「💾 儲存修改內容」。
   - 變更尺寸為 `XL` 或調整數量，點擊儲存，清冊內容與統計金額即時同步更新。
3. **截止前取消訂單**：
   - 點擊訂單右側「🗑️ 取消」，系統彈出確認對話框。
   - 點擊確定後，該筆訂單永久自 localStorage 清冊移除，總件數與金額隨之扣減。
4. **球經手動切換付款狀態**：
   - 點擊「標記已付」或「標記未付」，標籤在「✅ 已付款」與「⏳ 未付款」間切換。
   - 頂部「已收款金額」與「待催收未付款」即時連動變更。
5. **各尺寸訂購總件數速查 (廠商提報)**：
   - 頂部看板即時匯總 XS、S、M、L、XL、2XL 各自的累計件數。
6. **多條件搜尋與篩選**：
   - 在搜尋框輸入隊員姓名（如「大明」），清單即時過濾。
   - 切換下拉選單「未付款名單」，清單只顯示未繳費訂單。
7. **匯出廠商相容 CSV**：
   - 點擊「📥 匯出 Excel 廠商訂購單 (CSV)」，自動下載 `.csv` 檔案，支援 Excel 直接開啟不亂碼。
8. **自動化單元測試**：
   - 終端機執行 `npm test`，自動驗證新增、修改、刪除、算錢與統計邏輯。

### 二、 練習出缺席管理模組測試 (已 100% 通過)
1. **建立與維護練習場次**：
   - 選擇日期（固定週一、週二），系統自動顯示星期提示與練習日綠勾。
   - 時間預設 18:00~22:00，場地選擇「甲場」、「乙場」、「丙場」或「丁場」。
   - 點擊「發布練習日程」，卡片即時新增至清單。
   - 支援「✏️ 編輯」場地與訓練重點，或點擊「取消場次」（取消的場次標記已取消且不計入出席分母）。
2. **隊員線上請假 / 晚到通報**：
   - 選擇排定的練習場次，選擇既有隊員姓名，假別可選「請假」或「晚到」。
   - 填寫原因（如：系上必修考試 / 打工晚到 30 分鐘）。
   - 送出後，請假紀錄獨立妥善保存，下方即時顯示留存假單。
3. **現場出席登記 (管理者點名面板)**：
   - 點擊任一場次的「📋 展開點名」，展開全隊點名表（沿用既有隊員名冊）。
   - 若隊員有提早送出請假/晚到申請，名冊旁自動提示「⚠️ 已提請假：[事由]」，球經一鍵審核。
   - 提供「出席」、「缺席」、「請假」、「未確認」四個切換按鈕，點擊即時儲存。
   - 尚未確認的隊員**不計入出席率分母，亦不自動視為出席**。
4. **全隊出席率統計與報表匯出**：
   - 支援選擇開始日期與結束日期區間篩選。
   - 表格呈現：背號、姓名、已結算應到場次、實際出席、缺席、請假、晚到、出席率進度條。
   - 點擊「📥 匯出全隊出席統計 (CSV)」，產生相容 Excel 且不亂碼的報表。
5. **雙模組整合單元測試**：
   - 終端機執行 `npm test`，球衣訂購（7 項）與出缺席（6 項）共 13 項測試全數綠燈通過。

### 三、 比賽報名與檢錄大表模組測試 (已 100% 通過)
1. **右上角隊名更新**：
   - 全站頂部導覽列顯示「系排排球隊」。
2. **大專盃正式報名檢錄大表 (痛點二解決)**：
   - 點擊「比賽報名管理」頁籤。
   - 點擊「📋 展開全隊正式報名檢錄表」，系統自動從隊員資料庫匯入：
     - 生活照大頭貼縮圖
     - 參賽背號、姓名、守備位置
     - **學號 (studentId)**
     - **身分證字號 (idNumber，中間自動遮蔽保護資安)**
     - **出生年月日 (birthDate)**
     - **在學證明與學生證檢核狀態 (5/5 齊全)**
   - 點擊「確認報名 / 取消參賽」，即時切換參賽狀態，賽事卡片名額人數自動連動。
3. **匯出正式大專聯賽報名表 (CSV)**：
   - 點擊「📥 匯出大專聯賽正式報名表 (CSV)」，產出相容 Excel 且不亂碼之完整報名清冊。
4. **全套整合單元測試**：
   - 終端機執行 `npm test`，球衣訂購（7 項）、出缺席（6 項）及比賽報名（3 項）共 16 項測試 100% 通過。
